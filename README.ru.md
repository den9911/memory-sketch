## Возможности

- Четыре предмета и таймер на 30 секунд
- Цвета пера, ластик и отмена действия
- Локальный экспорт PNG и ссылки на задания

**Попробуй: Выбери → нарисуй → сравни → сохрани.**

Документация: English / Русский. Интерфейс приложения: English, Русский; выбор языка вручную или по настройкам браузера. По умолчанию тема системная; доступны ручные светлая и тёмная. Системный режим реагирует на смену темы устройства, выбор сохраняется локально.

## Запуск

Раздай каталог `public/` через статический HTTP-сервер:

```sh
python3 -m http.server 8080 --directory public
```

Открой http://localhost:8080. Прямой запуск через `file://` не поддерживается: ES-модулям нужен HTTP. В продакшене не нужны Node.js, база данных, API-ключи или сборка.

## Размещение и данные

Скопируй содержимое `public/` на статический хостинг. Абсолютные пути рассчитаны на корень домена; для подпапки GitHub Pages нужно адаптировать пути или использовать свой домен. Черновики и настройки хранятся на устройстве, PNG создаётся локально. Очистка данных сайта удаляет черновики.

## Как это устроено

Автоматического распознавания рисунков нет. Холст работает с мышью и касанием; рисование требует указательного устройства.

## Проверки и разработка

Нужен Node.js 24+.

```sh
npm ci
npm run typecheck
npm run build
npm run check:generated
npm test
npm run check
```

Сгенерированный JavaScript сохранён в репозитории. TypeScript используется для `src/preferences*.ts`; `src/contracts.ts` описывает формы данных. Остальные модули пока написаны на JavaScript. После изменения TypeScript пересобери проект. Компилятор работает в строгом режиме с проверкой индексного доступа и точных необязательных свойств; при ошибках код не генерируется. Сборка выпускает ES2022 и две языковые версии, CI проверяет типы, актуальность генерации, поведение и бюджет ресурсов.
